**Project Overview:**

In this project, we trained 3 models on two separate datasets in order to predict the numerical values of two emotions: 1. Arousal, 2. Valence. 

**Code organization:**

The code has been organized into two python notebooks. The first notebook (group5_dataset1_regression.ipynb) contains the code that trains the models for Dataset 1. The second notebook shagufta_data_preprocessing.ipynb contains the code that trains the models for Dataset 2.

**Instructions to run code:**

1. Clone this repository to your local machine. 
2. Press "Restart session and run all" inside each notebook
